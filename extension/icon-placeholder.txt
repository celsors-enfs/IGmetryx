NOTE: Extension icons are required for the extension to work properly.

You need to create the following icon files:
- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)  
- icon128.png (128x128 pixels)

These icons should be placed in the /extension directory.

You can create simple placeholder icons or use a design tool to create proper icons with the IGmetryx branding.
