# 📦 Como Instalar a Extensão Chrome

## Passo a Passo Rápido

1. **Abra o Chrome** (ou Edge, Brave, etc.)

2. **Vá para a página de extensões:**
   ```
   chrome://extensions/
   ```
   Ou: Menu (⋮) → Mais ferramentas → Extensões

3. **Ative o Modo Desenvolvedor:**
   - No canto superior direito, ative o toggle **"Modo do desenvolvedor"**

4. **Carregue a extensão:**
   - Clique em **"Carregar sem compactação"** (Load unpacked)
   - Navegue até: `/Users/celso/Desktop/IGmetryx0/extension`
   - **Selecione a pasta `extension`** e clique em "Selecionar"

5. **Pronto!** A extensão deve aparecer na lista.

## 🎯 Como Testar

1. Vá para a página: `/instagram/feed-snapshot` no seu site
2. A extensão deve ser detectada automaticamente
3. Se não detectar, recarregue a página (F5)

## ⚠️ Resolução de Problemas

### Extensão não aparece
- ✅ Certifique-se de ativar o "Modo do desenvolvedor"
- ✅ Selecione a pasta `extension` correta (não uma pasta dentro dela)

### Extensão não é detectada
- ✅ Recarregue a página da web após instalar
- ✅ Verifique se está na rota `/instagram/feed-snapshot`
- ✅ Abra o console do navegador (F12) para ver erros

### Erros ao usar
- ✅ A extensão só funciona em páginas do Instagram (instagram.com)
- ✅ Certifique-se de que o perfil é público
- ✅ Recarregue a extensão (botão de atualizar na página de extensões)

## 📝 Nota sobre Ícones

Os ícones (icon16.png, icon48.png, icon128.png) são opcionais. A extensão funcionará mesmo sem eles, mas o Chrome mostrará um ícone padrão.
